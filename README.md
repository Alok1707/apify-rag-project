# Apify RAG Project

A Retrieval-Augmented Generation (RAG) application built with Python using Apify for web scraping and AI frameworks for data retrieval and querying.

## 🚀 Features
- Web data scraping & extraction using Apify
- Text chunking and vector embeddings
- Question-answering over custom datasets

## 🛠️ Tech Stack
- **Language:** Python 3.13
- **Package Manager:** `uv`
- **Environment & Tools:** VS Code, Git/GitHub
